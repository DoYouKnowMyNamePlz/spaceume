# GitHub upload for Spaceume

Plasma 6 panel spacer that controls audio volume via scroll wheel and middle-click.

## Repository contents

- `package/` — Plasma applet package (metadata.json, contents/ui/, contents/config/)
- `install.sh` — manual install script
- `LICENSE` — GPL-2.0-or-later
- `README.md` — description, installation tutorial, configuration
- `Spaceume-Volume.png` — screenshot

## Install

```bash
chmod +x install.sh
./install.sh
```

Then add Spaceume to your panel via Plasma's **Add Widgets** dialog.

## KDE Store

Packaged as `spaceume-1.0.0.plasmoid` for upload to store.kde.org under the
Plasma Desktop Applets category.
